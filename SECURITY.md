# Security Policy

## Supported Versions

Only the latest version of this package is actively supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this package, please send an e-mail to the maintainer.
All security vulnerabilities will be promptly addressed.
